# Fog Show

Never ask the user to verbalize taste — "what does modern mean to you?" produces noise. Show, and read the reaction.

One decision per round. Produce 3–5 variations that are **wildly different, not shades** — if two would draw the same reaction, replace one. Label each with the belief it bets on ("this one bets density beats whitespace") so a reaction reveals the criterion, not just a preference.

Cheap and disposable: visual → one self-contained HTML file, fake data, no wiring; approaches → a one-screen sketch each (the idea, what it optimizes for, its sharpest tradeoff).

The deliverable is a sentence, not the artifact: "you consistently rejected X, so the real requirement is Y." Write that sentence to the ledger as resolved — it is now spec. If nothing lands, the decision space was framed wrong; reframe and rerun rather than generating more of the same.
